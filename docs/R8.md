# Optimización de la aplicación con R8

Puedes habilitar la reducción de código y recursos de tu app sin cambiar la inicialización de BecomeDigital. Conserva las dependencias indicadas en la [guía de instalación](../INSTALACION.md).

## Configuración de la aplicación

En `app/build.gradle`:

```groovy
android {
    buildTypes {
        release {
            minifyEnabled true
            shrinkResources true
            proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'),
                'proguard-rules.pro'
        }
    }
}
```

Conserva las reglas de compatibilidad incluidas con la SDK y sus dependencias. Agrega a `proguard-rules.pro` solo las reglas adicionales que requiera tu propia aplicación. Evita excluir toda la SDK de la optimización o silenciar todas las advertencias para resolver un problema de integración.

Con Android Gradle Plugin 9.0.1, utiliza las opciones predeterminadas de R8. Si tu app conserva las propiedades `android.nonFinalResIds=false`, `android.r8.strictFullModeForKeepRules=false` o `android.r8.optimizedResourceShrinking=false`, retíralas y conserva las opciones de instalación indicadas para esta entrega.

## Comprobar la versión que vas a publicar

Prueba en un dispositivo físico la versión de publicación de tu app: permisos, captura de los lados del documento, reintentos, validación facial, cancelación, idiomas y resultados. El tamaño final depende de las funciones y dependencias de la aplicación.

Conserva el archivo `mapping.txt` de cada versión de tu app para analizar posibles errores de esa entrega con soporte.
